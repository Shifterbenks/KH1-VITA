# Couleurs du smoke test Vita

L'application n'embarque aucun art du jeu.

- bandeau bleu : le starter a démarré ;
- premier grand rectangle vert : un ELF reconnu est présent ; rouge : ELF absent ;
- second grand rectangle vert : le dossier `kingdom` contient des fichiers ; orange : vide ;
- barre basse verte : payload minimal trouvé ; orange : incomplet ;
- bandeau rouge : erreur d'initialisation.

Boutons :

- **Croix** : rescanner les fichiers ;
- **START** : quitter.
